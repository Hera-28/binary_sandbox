# Interactive Binary Math & Logic Visualizer

A lightweight Python tool designed to make binary arithmetic and bitwise logic operations intuitive and easy to understand through step-by-step visual execution.

## Key Features
- Visual Binary Addition: Break down binary addition bit-by-bit showing carry propagation in real time.
- Decimal-to-Binary Conversion: Step-by-step breakdown using standard repeated division algorithms.
- Bitwise Logic Playground: Instantly inspect AND, OR, and XOR logic outputs on binary representations.
